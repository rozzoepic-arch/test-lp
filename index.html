Tentang Saya

Menghubungkan teori perkuliahan teknik elektro dengan penerapan praktis di bidang sistem tertanam, jaringan telekomunikasi nirkabel, dan rekayasa antarmuka pemantauan.

Saya mahasiswa Teknik Elektro di Universitas Musamus Merauke dengan konsentrasi Teknik Komputer dan Telekomunikasi. Saya tertarik pada cara sensor membaca kondisi sekitar, perangkat saling terhubung, dan data ditampilkan melalui dashboard yang mudah dipahami. Portofolio ini menjadi tempat saya menyusun ide dan mendokumentasikan proses belajar.

[SYS_FOCUS: 01]

Perangkat dan Sensor

Interfacing mikrokontroler (ESP32/Arduino), pembacaan sensor suhu dan kelembapan, modul arus listrik, dan kalibrasi sinyal dasar.

GPIO • I2C • ADC • Sinyal Analog/Digital
[SYS_FOCUS: 02]

Jaringan dan Telekomunikasi

Penerapan protokol ringan IoT, mekanisme MQTT publish/subscribe, transmisi paket data nirkabel melalui kanal Wi-Fi hingga topologi nirkabel sederhana.

MQTT • Wi-Fi • TCP/IP • Transmisi Data
[SYS_FOCUS: 03]

Visualisasi Data

Pembuatan dashboard web responsif, antarmuka telemetri data dengan pembaruan dinamis, representasi visual tren grafis, serta monitoring kondisi simpul secara terstruktur.

Web Dashboard • SVG Charts • UI/UX Responsif

Teknologi yang ingin dieksplorasi:

Perkakas perangkat keras, protokol transmisi data, dan antarmuka web.

ESP32 MQTT HTML CSS JavaScript

Konsep Proyek yang Ingin Saya Bangun

Rancangan awal berbasis studi kasus di lingkungan kampus dan laboratorium. Seluruh inisiatif di bawah berstatus konsep persiapan eksplorasi.

Monitoring Suhu dan Kelembapan

Konsep
[ID: PRJ-ENV-01] • Pemantauan Lingkungan Ruang & Laboratorium
ESP32 DHT22 MQTT HTML & CSS JavaScript

Konsep pemantauan kondisi ruangan melalui sensor dan tampilan data yang mudah dibaca.

Lihat konsep
> Masalah: Perubahan kondisi ruangan sulit diketahui tanpa pencatatan berkala dan riwayat data.
> Rencana Solusi: Membaca suhu dan kelembapan lalu menyajikan nilai terkini beserta riwayat pada dashboard web yang intuitif.
> Langkah Awal: Membuat simulasi antarmuka peramban, lalu mencoba pembacaan sensor jika mikrokontroler dan modul sensor sudah siap.

Monitoring Konsumsi Energi

Konsep
[ID: PRJ-PWR-02] • Pemantauan Beban Daya & Akumulasi kWh
Data simulasi JavaScript Sensor Arus/Tegangan

Konsep dashboard untuk memahami daya dan akumulasi penggunaan energi.

Lihat konsep
> Masalah: Pola konsumsi energi sulit dipahami jika hanya melihat angka tagihan atau angka terpisah tanpa visualisasi tren.
> Rencana Solusi: Menampilkan daya aktif dalam watt dan akumulasi energi dalam kWh secara terstruktur pada layar pemantauan.
> Langkah Awal: Menyiapkan dataset simulasi dan merancang visualisasi antarmuka sebelum menentukan perangkat pengukuran fisik.

Monitoring Kualitas Jaringan

Konsep
[ID: PRJ-NET-03] • Diagnostik Latensi & Keandalan Paket
Data simulasi JavaScript Pengumpul Data Jaringan

Konsep visualisasi latensi dan packet loss untuk membaca perubahan kualitas koneksi.

Lihat konsep
> Masalah: Perubahan kualitas jaringan sulit diikuti tanpa adanya pencatatan riwayat diagnostik secara berkala.
> Rencana Solusi: Menampilkan latensi dalam ms dan packet loss dalam % pada antarmuka grafik yang mudah dianalisis.
> Langkah Awal: Membuat data simulasi dan merancang grafik yang mudah dibaca sebelum menyusun modul pengumpul data.
