Konsep

[ID: PRJ-ENV-01] • Lingkungan Ruang Server / Lab Komputasi

ESP32 DHT22 MQTT Web Dashboard

Tantangan: Fluktuasi termal dan kelembapan ekstrem pada rak server kampus yang berisiko memperpendek umur pakai perangkat komputasi jika tidak terdeteksi sejak dini.

terminal Lihat konsep detail expand_more
> Masalah: Pengecekan temperatur manual berkala rentan kelalaian human error dan tidak menyajikan riwayat historis saat terjadi lonjakan mendadak pada malam hari.
> Rencana Solusi: Pemasangan simpul sensor DHT22 terhubung mikrokontroler ESP32 bertenaga baterai dengan mode deep-sleep, mempublikasikan paket payload JSON berkala via broker MQTT menuju dashboard web ringan.
> Langkah Awal: 1. Pembuatan breadboard circuit test DHT22 + ESP32. 2. Kalibrasi offset sensor dengan termometer acuan. 3. Uji coba pengiriman topik MQTT di jaringan intranet lokal.

Monitoring Konsumsi Energi

Konsep

[ID: PRJ-PWR-02] • Pemantauan Beban Daya & Efisiensi Listrik

ESP32 Sensor PZEM-004T Modbus/TTL Web Dashboard

Tantangan: Tingginya pemborosan energi pada workstation lab praktikum akibat perangkat periferal yang tetap berada pada mode siaga (standby) saat jam operasional usai.

terminal Lihat konsep detail expand_more
> Masalah: Kurangnya visibilitas data konsumsi Watt, tegangan drop, dan akumulasi kWh secara riil pada masing-masing meja kerja praktikum elektronika.
> Rencana Solusi: Mengintegrasikan modul sensor tegangan/arus PZEM-004T non-intrusif dengan mikrokontroler untuk mengalkulasi faktor daya secara berkala serta mengirimkan sinyal telemetri beban berlebih.
> Langkah Awal: 1. Perancangan skema isolasi optocoupler demi keselamatan arus bolak-balik (AC). 2. Penulisan parser UART PZEM di ESP32. 3. Perancangan UI indikator gauge beban daya di peramban.
network_check

Monitoring Kualitas Jaringan

Konsep

[ID: PRJ-NET-03] • Analisis Latensi & Packet Loss Nirkabel

ESP32 Ping Wi-Fi RSSI WebSockets Web Dashboard

Tantangan: Fluktuasi koneksi Wi-Fi kampus di sudut-sudut gedung laboratorium yang kerap terputus tanpa rekaman diagnostik waktu nyata untuk penanganan tim IT.

terminal Lihat konsep detail expand_more
> Masalah: Keluhan pengguna mengenai internet lambat sulit dianalisis jika tidak ada sensor ujung (endpoint tester) yang terus memantau metrik jitter, RTT, dan level desibel (RSSI).
> Rencana Solusi: Sebuah node portabel berbasis ESP32 yang mengirimkan paket uji ICMP secara berkala ke gateway lokal dan DNS publik, lalu memetakan respons latensi secara instan melalui kanal WebSockets.
> Langkah Awal: 1. Implementasi library ESP32 Ping asinkron. 2. Pengukuran akurasi scan Wi-Fi beacon dBm. 3. Pembuatan tampilan scatter plot latensi real-time di antarmuka HTML/CSS.
