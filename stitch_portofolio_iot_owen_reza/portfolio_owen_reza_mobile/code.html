Konsep Proyek yang Ingin Saya Bangun

Konsep SYS_ID: ENV-01

Monitoring Suhu & Kelembapan

Telemetri kondisi iklim mikro laboratorium dan ruang server secara nirkabel dengan pencatatan otomatis berkala.

Lihat konsep expand_more

> Masalah:

Pencatatan suhu laboratorium masih sering dilakukan manual, sehingga fluktuasi panas berlebih terlambat terdeteksi.

> Rencana Solusi:

Menempatkan node sensor DHT22 terhubung modul ESP32 yang mempublikasikan data ke broker MQTT lokal setiap 10 detik.

> Langkah Awal:

Merakit prototipe breadboard, menguji kestabilan pembacaan GPIO, dan memetakan payload JSON pada dashboard web.

Konsep SYS_ID: PWR-02

Monitoring Konsumsi Energi

Pencatatan beban arus, tegangan, dan estimasi konsumsi daya listrik perangkat elektronika untuk pencegahan lonjakan beban.

Lihat konsep expand_more

> Masalah:

Ketidaktahuan terhadap besaran daya aktif peralatan kampus menyebabkan boros energi dan risiko beban lebih.

> Rencana Solusi:

Memanfaatkan sensor CT non-invasif (SCT-013) serta IC PZEM-004T dengan kalkulasi daya otomatis di sisi firmware.

> Langkah Awal:

Kalibrasi pembacaan RMS terhadap multimeter standar dan menyusun alert logic bila arus melebihi ambang batas.

Konsep SYS_ID: NET-03

Monitoring Kualitas Jaringan

Pemantauan latensi (ping), jitter, dan packet loss pada titik akses jaringan nirkabel lokal untuk diagnosa stabilitas sinyal.

Lihat konsep expand_more

> Masalah:

Sinyal Wi-Fi sering mengalami drop sesaat tanpa pencatatan waktu yang pasti untuk evaluasi teknisi jaringan.

> Rencana Solusi:

Node pemeriksa ringan berbasis mikrokomputer yang secara periodik mengirimkan probe ICMP ke gateway utama.

> Langkah Awal:

Membuat script socket UDP/TCP sederhana dan visualisasi persentase packet loss dalam grafik timeline.
